Modified, 2026-09-05, to fit a context budget. Whole sections were
REMOVED; not one word was rewritten, so every sentence still present
is the author's own:

  test-driven-development/SKILL.md            2219 -> 1589 tokens
      removed: 'Common Rationalizations', 'Example: Bug Fix',
               'Debugging Integration'
  test-driven-development/writing-good-tests.md  1774 -> 838 tokens
      removed: the prose of 'Principle 1: Name the Break' and
               'Principle 2: Exercise the Real Thing'
      kept:    both of their 'Gate Function' blocks, gathered under a
               'Gate functions' heading

Why: these files are read into a local model's context window on every
call, and on a 6 GB card every token of context is paid for in model
weights that no longer fit on the GPU. The removed sections argue for
the practice; this harness enforces it instead, because a test gate
stops the run. The gate functions were kept for the same reason: they
are checks the model applies, not arguments it has to be persuaded by.
